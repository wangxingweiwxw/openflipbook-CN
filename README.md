# 中文化openflipbook
我一直觉得读人文历史最难的不是找资料，而是怎么走进去。厚书、年表、专有名词一上来，人就容易停在门口。有没有一种方式让第一眼是画面，下一眼是好奇点一下就能往更深处走？wellplay好玩就是冲着这件事做的。它是一个绘本即界面的探索工具。每一页都是一张 AI 生成的插画。你在画面上点任何地方，系统会理解你点中的内容并生成下一页。顺着你的兴趣继续讲下去。像翻绘本，也像在地图上走路。路径由你点出来，而不是被目录推着走。
 
它能做什么
打开首页可以输入一个主题，比如明思宗崇祯皇帝、清朝兴衰史、资治通鉴科普亦或是北京旅游攻略。几秒后会出现一张带说明感的画面。对某个物件、某个人物、某段文字感兴趣，点一下就会围绕那个局部展开新的一页。放大细节、讲清背景或转入相邻话题。也可以上传一张现成图片当起点，再从画面里往外挖。会话可以发布到作品画廊，别人能点进已发布的案例继续探索。完整案例库在全部案例里，按发布时间从早到晚排列。首页会固定展示画廊中较早发布的若干会话，方便一眼看到项目在讲什么。
	 
对我来说，它更像一本可点击的人文绘本，让看->点->再看变成阅读节奏。历史人物、旅游攻略、城市与技术都可以先落成画面，再由点击决定下一站。探索时顶部的地图会把当前会话里已经点过的页面摊成一张关系图。谁从谁长出来、你走到了哪一页。一眼能看清整条路径，再点回去继续翻。若想把整场探索铺得更大、更适合慢慢逛，点画布会在新窗口打开完整布局图。页面像钉在画布上的卡片，可缩放、拖动、总览全局。再随时跳回某一页接着点，一个管我在哪一个管整本绘本摊开长什么样。
 
探索告一段落时可以在当前页面右键把这一页存成明信片样式图。画面、标题和可回访的链接收进同一张竖版卡片里，方便转发或留作纪念。若想带走整段点选路径，同一菜单里还能导出路径。选PDF得到可翻阅的图文册，选ZIP打包沿途每一页原图，选GIF则把探索轨迹收成可循环播放的动图。同一条故事线按你需要的分享方式带走。
 
它从哪来
项目的起源
当我看到知乎人文季活动用Vibe Coding做项目探索人文历史的时候，我脑海里首先想到的就是flipbook.page 。这个国外网站非常有意思且火热，但是中文化不完美。基于开源项目通过Vibe Coding建造真正中国风绘本探索网站是这个wellplay好玩项目的起源。
flipbook有不错画风和新颖AI即时生成图片无限点击交互，中文化不完美↓
 
使用了来自Github.com的开源项目openflipbook作为基础进行Vibe Coding中文绘本化。起初的效果中文有改善但还时常出现乱码，画风不太满意且不稳定。模型的适配和风格调整都需要花费很多精力，通过Cursor的Vibe Coding助力不少。
起初的效果中文有改善但还时常出现乱码，画风偏向阴暗写实↓
 
技术上wellplay站在开源项目openflipbook之上前端是Next.js，后端是 Python FastAPI。图像与视觉理解通过可替换的模型接口接入。你可以自备密钥、自托管存储与数据库，用Docker部署成可公网访问的站点。我在此基础上做了面向人文阅读的产品化包装。首页与案例画廊、中文交互文案、发布与继续探索的路径以及用绘本探索人文历史这条主线。

本项目也是我在知乎人文季 Vibe Coding 方向上的一次实践，去试AI+人文能不能变成一种轻松的进入方式。感谢开源项目的分享，这是一个非常扎实的起点。下一步会把力气放在画面之上再接通视频流。让关键场景能动起来、流起来。实时视频流也是 flipbook.page 最核心的创新之一，但要亲手体验门槛很高。wellplay会尽量把这条能力铺平、接稳，让更多人真正用得上。让用绘本探索人文历史，从翻到下一页再往前一步，变成走进正在发生的一幕。
 
我想传递什么
人文不该只能是考试和学术。它也可以是一张图、一次点击、一条自己点出来的故事线。wellplay帮你降低走进去的门槛。先被画面抓住，再按兴趣深入。想停就停，想钻就钻。若你对项目细节、二次开发或基于这套能力做定制绘本/主题探索站感兴趣，欢迎联系交流。

## 项目的起源
> **开源中文化的 [flipbook.page](https://flipbook.page) ，绘本就是用户界面。** 每一页都是AI生成的图示。点击图片的任何地方由视觉推理模型识别点击区域，生成进一步下一页的交互。以一个提问或者上传的图片为种子，带你用绘本探索人文历史。

## 快速开始

最快的途径是通过Docker部署, 配置大语言模型和图片生成模型API，然后打开网页开始体验:

```bash
git clone https://github.com/wangxingweiwxw/openflipbook-CN
cd openflipbook

cp .env.example .env          # fill FAL_KEY + OPENROUTER_API_KEY
dockers compose up --build    # → http://localhost:3000/play
```
